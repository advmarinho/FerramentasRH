Sobre o Projeto

O PDF Protect Tool é uma ferramenta desenvolvida para auxiliar profissionais de RH, DP e demais interessados na proteção de arquivos PDF. Com uma interface gráfica intuitiva, o sistema extrai o CPF contido no PDF e protege o documento utilizando o CPF como senha ou uma senha personalizada definida pelo usuário. Além disso, gera um rascunho de e-mail no Outlook com o PDF protegido anexado, facilitando a comunicação.

Funcionalidades

  • Proteção Automática: Extrai o CPF do PDF e protege o arquivo utilizando-o como senha.
  • Proteção Personalizada: Permite definir manualmente uma senha para proteger o PDF.
  • Integração com Outlook: Cria automaticamente um rascunho de e-mail com o PDF protegido anexado.
  • Interface Moderna: Desenvolvida com CustomTkinter para uma experiência de usuário aprimorada.

Instalação

Requisitos: Python 3.7+ e as seguintes dependências:

  • customtkinter
  • tkinter (incluso na maioria das instalações do Python)
  • PyPDF2
  • pikepdf
  • pywin32 (para integração com o Outlook)
  • pandas (para funcionalidades de log, se necessário)
  • pyfiglet (opcional, para exibição de um banner)

Para instalar as dependências, execute o seguinte comando no terminal:

pip install customtkinter PyPDF2 pikepdf pywin32 pandas pyfiglet

Gerando um Executável e Uso

Para gerar um único executável (sem a janela de console) utilizando o PyInstaller, execute:

pyinstaller --onefile --noconsole --add-data "gui;gui" main.py

O executável será criado na pasta dist. Ao executá-lo, a aplicação realizará as seguintes etapas:

  • Seleção do PDF: O usuário escolhe o arquivo PDF através de uma janela de diálogo.
  • Processamento do Arquivo: O sistema extrai o CPF, protege o PDF com uma senha (automática ou personalizada) e gera um rascunho de e-mail no Outlook com o PDF protegido anexado.
  • Feedback Visual: Mensagens e indicadores informam o status do processamento.
